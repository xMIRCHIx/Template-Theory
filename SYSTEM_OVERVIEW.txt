1. WHAT IS THIS WEBSITE ABOUT?
--------------------------------------------------------------------------------
Cinevo (Template Theory) is a high-performance Headless E-Commerce storefront
for modern creators, video editors, photographers, and designers.

Products Sold:
- Cinematic 3D LUTs (.CUBE, .3DL, .LOOK for Premiere Pro, DaVinci, FCPX)
- Lightroom Presets (.XMP, .DNG for Desktop and Mobile)
- Editorial & Display Fonts (.OTF, .TTF, .WOFF2 with live interactive type tester)
- Layered Photoshop Templates (.PSD with smart objects & mockups)
- Creator Albums & Digital Lookbooks

Tech Stack:
- Frontend: React 18 + Vite 6 + TypeScript
- Styling: Pure Vanilla CSS (Claymorphism & warm earthy design tokens)
- Animations: Framer Motion + Canvas Confetti + Hardware-Accelerated CSS
- Backend: Shopify Storefront GraphQL API (Headless Architecture)
- Hosting: Vercel Global Edge Network (with Netlify/Cloudflare compatibility)


2. HOW IT WORKS (FRONTEND ARCHITECTURE & DATA FLOW)
--------------------------------------------------------------------------------
Flow Overview:
1. User opens website -> Hosted on Vercel Edge CDN.
2. React SPA initializes -> React Router v6 handles client-side routing.
3. ShopifyContext executes GraphQL query (GET_ALL_PRODUCTS_QUERY) to fetch
   live products from Shopify.
4. If Shopify API is active, real-time products render with prices in INR/USD.
   If offline, it smoothly falls back to local data (src/data/products.ts).
5. User adds items to Cart -> Stored in CartContext and localStorage.
6. User clicks "Buy Now" or "Checkout" -> Shopify cartCreate mutation generates
   a direct official Shopify checkout URL (https://template-theory-2.myshopify.com/checkouts/...)
7. User pays securely on Shopify (UPI, Cards, NetBanking, Razorpay, PayPal) ->
   Shopify processes payment and delivers digital downloads.


3. HOW IT IS CONNECTED WITH SHOPIFY
--------------------------------------------------------------------------------
Files:
- src/services/shopify.ts (GraphQL queries, mutations, mappers, API calls)
- src/context/ShopifyContext.tsx (Global state provider & Buy Now triggers)

Environment Variables in .env:
  VITE_SHOPIFY_STORE_DOMAIN=template-theory-2.myshopify.com
  VITE_SHOPIFY_STOREFRONT_TOKEN=e9c5ed69764a1c1ee180980e3e8a5434
  VITE_SHOPIFY_API_VERSION=2024-07

Key Features of Shopify Integration:
- Real-time catalog syncing: Any product created/updated in Shopify Admin
  automatically appears on this website.
- Auto-Categorization (inferCategory):
  * Titles/Tags with 'lut' or 'cube' -> LUTs
  * Titles/Tags with 'preset', 'xmp', 'dng' -> Presets
  * Titles/Tags with 'font', 'serif', 'otf' -> Fonts
  * Titles/Tags with 'psd', 'mockup' -> PSDs
  * Titles/Tags with 'album', 'lookbook' -> Albums
- Direct Checkout Session: Uses cartCreate GraphQL mutation to send
  merchandiseId (Shopify variant ID) and quantity to create a direct checkout URL.

7. MIGRATION GUIDE (HOW TO RUN ON ANOTHER SYSTEM / ANOTHER ANTIGRAVITY AGENT)
--------------------------------------------------------------------------------
1. Clone / Copy Repository to new system:
   git clone https://github.com/xMIRCHIx/Template-Theory.git
   cd Template-Theory

2. Install dependencies:
   npm install

3. Verify .env file:
   Make sure .env contains:
   VITE_SHOPIFY_STORE_DOMAIN=template-theory-2.myshopify.com
   VITE_SHOPIFY_STOREFRONT_TOKEN=e9c5ed69764a1c1ee180980e3e8a5434
   VITE_SHOPIFY_API_VERSION=2024-07

4. Run locally:
   npm run dev

5. Build for production:
   npm run build
