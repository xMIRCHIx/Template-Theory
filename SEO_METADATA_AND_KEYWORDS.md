## 🔍 4. Technical SEO Implementations in Codebase

1. **`src/utils/seoConfig.ts`**:
   - Master configuration object (`SITE_SEO_CONFIG`)
   - Pre-computed SEO metadata for every core page and collection
   - Hashtag banks for instant copy & programmatic export
   - JSON-LD Schema generators (`Organization`, `WebSite`, `Product`, `CollectionPage`, `BreadcrumbList`, `FAQPage`)
2. **`src/components/common/SEOHead.tsx`**:
   - Dynamic Head updater for titles, meta descriptions, canonical URLs, robots, OpenGraph (WhatsApp, Facebook, Pinterest), and Twitter cards.
   - Dynamic injection of `<script type="application/ld+json">` for rich Google search result badges.
3. **`public/robots.txt`**:
   - Full indexing allowed for all public pages while protecting `/admin`, `/checkout`, and `/order-success`.
   - Full access enabled for social crawlers (Twitterbot, WhatsApp, Facebook, Pinterest).
4. **`public/sitemap.xml`**:
   - XML sitemap index registered for rapid Google Search Console and Bing Webmaster submission.
